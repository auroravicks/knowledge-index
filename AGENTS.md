# Study knowledge instructions

Use the private Resources directory configured in `config.yml` as the evidence base.

1. Read `Resources/CATALOG.md` before broad research.
2. Search `Resources/.knowledge/searchable` with `rg`; narrow by subject before broadening.
3. Search exact terms, synonyms, abbreviations, and closely related concepts iteratively.
4. Inspect surrounding lines with context rather than quoting isolated matches.
5. Cite the subject, source filename, and page, slide, cell, or transcript timestamp marker.
6. Separate sourced statements from inference. Say when evidence is incomplete.
7. Never edit original Transcripts, Captions, Notes, or Assignments files.
8. Write derived material only under each subject's `Study Guides` directory.
9. Do not upload private course files or extracted searchable text to Git.
